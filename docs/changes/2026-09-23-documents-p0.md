## 修掉的那个隐患（本期真正的理由）

客户页上原来那个附件上传（AttachmentUpload）走的是 /api/upload → **公开 URL** → Attachment 表。
意思是：客户身份证一旦传上去，**任何拿到链接的人都能看**，而且链接转发出去就收不回来。

现在换成 Document：文件进私有桶（private/ 前缀），页面里**没有任何直链**，
每次打开都走 /api/documents/[id]/file 做三重校验 —— 身份、组织、分行 + 模块权限 —— 并写一条下载审计。

## 做了什么

| 部分 | 内容 |
| --- | --- |
| 表 | Document（28 列）：kind / status / storageKey / sha256 / 八个显式外键 / 审核留痕 / retainUntil / legalHold / 软删 |
| 纯规则 | lib/documents/validate.ts：类型白名单（**刻意排除 svg 与 html** —— 它们在浏览器里是代码）、20MB 上限、保留期（财务单据 7 年、客户证件 12 个月…）、按关联对象决定看哪个模块的权限 |
| 服务 | modules/documents/service.ts：**先建行再传文件，传失败就把行删掉**（宁可没有记录，也不要一条指向不存在文件的记录） |
| 出口 | /api/documents/[id]/file —— 镜像考勤照片那套（那套已经过实践）：校验后才从私有桶取字节，private/no-store |
| 界面 | 客户页的文档面板：上传、状态徽章（待审核/已审核/已驳回）、打开、审核/驳回、软删 |
| 权限 | 写 = 该模块 edit；审核 = 同上 + 非机修（老板：manager 也可以）；**删除 = 只有 OWNER / SUPER_ADMIN** |
| 顺带 | 删掉已无引用的旧组件；Attachment 模型标注弃用（**但不能删** —— 构建期同步拒绝 DROP，会直接让部署失败） |

## 验收标准（老板要的那条）达成方式

「上传后，**未授权访问该文件必须失败**」—— 测试里逐条钉死了边界：

- 跨组织：B 组织的 OWNER 看不了 A 组织的文档 ✅
- 跨分行：同组织不同分行的 MANAGER 看不了 ✅
- 无模块权限的机修看不了别人的 ✅
- 上传者本人可以看（哪怕他没有该模块权限）✅
- org 级角色跨分行可以看 ✅

另外钉住：只存私有键（**断言 storageKey 不含 http**）、sha256 稳定、保留期算得出、
审核留痕、软删后列表看不到但行还在（审计要留得下来）。

## 顺手修了一个测试隔离问题（不是产品问题）

全量跑时 tests/invoice-number.test.ts 红了：那个发票计数器是**按年份全局**的（生产语义正确），
而并行跑的完工链路测试也在推进同一个计数器 —— 我的断言拿到了被它们推进过的值。
修法是让这个测试用**合成年份 2099**，与并行测试彻底隔离，并把原因写在注释里。
教训与"偶发失败"那条同源：**单独跑绿、并行跑红，先怀疑共享状态。**
