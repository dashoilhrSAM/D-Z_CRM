## 老板要的那件事，v1 做的是「零件」这一张

原话：「有没有办法通过一个 excel 就能完成整个 workshop 的 set up……下载模板、改、重新上传就更新」。
方案（docs/DOCUMENTS_AND_BULK_SETUP_PLAN.md）批准的 v1 是三张 sheet（Products / Packages / Campaigns）。
**动手时发现后两张现在做不了**，原因见文末 —— 先把最大的痛点（82 个 SKU、价格常改）做透。

## 流程（这一期的全部设计就在这五步里）

    ① 下载：**导出你现在的配置**（不是空模板 —— 空模板逼你重录，而且没填的字段会被当成「要清空」）
    ② 在 Excel 里改
    ③ 上传：**只解析与校验，不写库**
    ④ 预览：逐行列出「新增 / 修改 / 删除 / 无变化 / 出错」，修改行带 **旧值 → 新值**
    ⑤ 应用：点确认才写库（一个事务），并写审计

## 三条安全规则（都写在代码里，也都被测试钉住）

1. **文件里没有的行，绝不删除** —— 要删必须在 _action 列显式写 delete。
   否则拿着上周的工作簿上传一次，之后新建的东西会全部消失。
2. **留空 = 不动**，不是清成 0。空单元格把价格清零是最容易发生、最难发现的事故。
3. **一张 sheet 里有一行出错，就整张不写**。半对半错比不写更糟。

另外：**未知供应商报错，不悄悄建一条**；**删除只允许 OWNER**（服务端在应用时判定，不是只在预览里）；
**有历史引用的零件不删、改成停用**（工单行/库存/库存流水指着它 —— 历史单据提过的东西不能抹掉）。

## 列定义沿用老板自己的模板

docs/setup-templates/05_产品目录.xlsx 的「列对照」表就是权威列名（SKU / Name / Category / Brand /
Unit / Sell Price / Cost Price / Min Stock / Safety Stock / Lead Time / Barcode / Part No /
Compatible Models / Supplier）—— 他已经在用那套表，另造一套只会让人困惑。
金额在文件里是 **RM**、系统里是 sen，转换只在导入导出这一层做。

## 闭环测试抓到的第一个真问题（值得记）

「导出 → 原样导入 = 零改动」这条测试第一次跑就红了：导出时我在数据表里加了第二行（中文列名），
而解析器把表头之后的一切都当数据 —— 那一行变成了三条假的 SKU 行。
**没有这条测试，这个格式矛盾会一直潜伏到老板第一次导入时才炸**（而且炸出来的是一堆假数据）。
修法：中文列名只放「列对照」sheet，数据表保持干净。

## 验证

- 新增 **15 条测试**：11 条纯差异规则（不进则不删 / 留空不动 / 出错就挡 / 金额与枚举归一 / 重复键 / 新旧值）
  + 4 条闭环（**往返一致**、改加删、有错不写、未知供应商报错）；
- 全量 **64 文件 / 772 测试**通过；tsc 与 eslint 干净；无残留测试数据。

## 套餐与促销：老板定了「分开导」

动手时发现 **ServicePackage 与 Campaign 都是按分店存的**（branchId），而 Product 是组织级、SKU 全局唯一。
所以先问了一句「导出哪个分店」—— 老板定：**分开导**（每个分店单独导出/导入）。

于是四张 sheet 齐了：**Products（组织级）+ Packages + Package Items + Campaigns（按分店）**。
关键设计：**分店写进文件里的隐藏元数据**，导入时**以文件里写的为准** ——
把 A 店的文件导进 B 店这件事在结构上就不可能发生（不是靠人记得选对下拉框）。
分行级用户只能导/写自己那一间；org 级可以选，但会写进审计。

套餐明细用**组合键**「套餐名 + 项目名」（同名项目允许出现在不同套餐里）。

## 又踩到两个坑（都被测试逮住）

1. **组合键的顺序**：明细的键我先写成「项目名 / 套餐名」，而应用代码按「套餐名 / 项目名」拆 ——
   报错是 Unknown package: Oil change。修法：键顺序按人的读法（先套餐后项目），且应用时**优先用字段值**，
   只有删除行（没有字段值）才回退到拆键。
2. **假差异**：导出会写供应商名，而预览用的「现状」里没有供应商名 —— 于是**每个有供应商的零件都会被误报成有改动**。
   假差异比不预览更糟（人会开始不信任预览，然后闭眼点确认）。已修，并加了一条带供应商的往返测试钉住它。
