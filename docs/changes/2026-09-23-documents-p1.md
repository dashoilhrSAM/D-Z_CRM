## 这一期补上「检索」与「到期」两半

P0 把文档**存对地方**了（私有桶、状态、权限、审计），但还缺两件需求里点名的东西：
**检索（怎么一眼看到哪些要处理）** 与 **保留期的执行（到期了会怎样）**。

## 做了什么

| 部分 | 内容 |
| --- | --- |
| **全局文档中心** /workshop/documents | 默认视图是**待审核 + 即将到期**（不是报表）；可按类型筛选；每行显示文件名/类型/关联对象/状态/到期日，并能直接打开 |
| **到期规则**（纯函数） | 过了到期日 → EXPIRE；30 天内 → WARN；**legalHold 永不自动动**；已软删/已归档/已过期的不重复处理 |
| **每日扫描** /api/cron/documents-expiry | 把到期的标成 EXPIRED + 给 **org 级账号**发一条汇总通知（不逐条发给所有人：一晚到期 50 份就变 50 条通知） |
| **工单页文档区** | 与 SOP 照片并列 —— 照片是「车当时的样」，文档是「这单相关的纸」 |
| 导航 | 新增「文档中心」（模块 CUSTOMERS，OWNER + 柜台可见） |

## 两条刻意的设计

1. **到期扫描不硬删**。方案里写的是「到期 → 归档 → 宽限期 → 硬删」，硬删留到 P4 ——
   它必须有人在场，因为这一步错了回不来。
2. **通知合并成一条**。逐文档逐人发通知，在真实用量下（一个客户几十份证件）会立刻变成噪声，
   而噪声通知等于没有通知。

## 验证

- 新增 5 条测试（到期判定 3 条 + 扫描 2 条）：EXPIRE/WARN/NONE 三档、legalHold 不动、
  已过期不重复处理、扫描只标到期且只通知 org 级账号、重复跑幂等；
- 全量 **62 文件 / 757 测试**通过；tsc 与 eslint 干净；无残留测试数据（含通知）。
